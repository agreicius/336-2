Definition 1.19.1. Public key cryptography (PKC).

A public key (or asymmetric) cryptosystem is a cryptosystem
\begin{align*} E\colon \mathcal{K}\times \mathcal{P} \amp \rightarrow \mathcal{C} \\ D\colon \mathcal{K}\times \mathcal{C} \amp \rightarrow \mathcal{P} \end{align*}
for which the keyspace \(\mathcal{K}\) consists of pairs \(k=(k_{\text{priv}},k_{\text{pub}})\text{,}\) called public/private key pairs, and such that for all \(k=(k_{\text{priv}},k_{\text{pub}})\text{,}\) we have
\begin{align*} E_{k} \amp = E_{k_{\priv}} \amp D_k\amp =D_{k_{\pub}} \end{align*}
so that encryption is performed using the public key \(k_{\pub}\) and decryption is performed using the private key \(k_{\priv}\text{.}\)
🔗
Cryptography that uses public key cryptosystems is called public key cryptography.
