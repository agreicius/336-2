Definition 1.19.6. Discrete log problem.

The discrete log problem for modular unit groups is the general problem described as follows: given a positive integer \(n\text{,}\) unit \(g\in (\Z/n\Z)^*\text{,}\) and element \(h\in \angvec{g}\text{,}\) find the unique integer \(a\in \{0,1,\dots \ord g-1\}\) such that \(h=g^a\) (i.e., compute \(\log_g h\)).
