Sage example 11. RSA: encryption and decryption.

We include below some encoding/decoding functions and RSA encryption/decrpytion functions.
🔗
Below we are setting up an RSA public key that uses \(e=3\) as the public exponent. For that reason, we make sure to pick our random large primes \(p\) and \(q\) so that \(\gcd(3,(p-1)(q-1))=1\text{.}\)
🔗
In the Sage cell below, choose your favorite lowercase string s, encode it as an integer, encrypt and decrypt it using the public key \((N,3)\text{,}\) and decode back to a string.
🔗
Below you find an intercepted RSA ciphertext \(c\text{,}\) the result of encoding a message \(s\) as an integer using str2int(s) and then encrypting this integer using the RSA public key \((N,e)=(N,3)\text{.}\) Using the provided informtation of \(N\) and \(\phi(N)\) (named phiN), find the secret message! (Hint: the command power_mod(a,b,M) computes \(a^b\pmod M\) for any integer power \(b\text{,}\) even negative ones!)
