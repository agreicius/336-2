Sage example 10. Elgamal encryption and decryption.

Below you find the relevant Sage functions for Elgamal encryption and decryption. We’e included our str2int() and int2str functions discussed in Subsection 1.19.3. Coding-wise, it is slighly more convenient here to work with integers, as opposed to congruence classes. You will notice that we use power_mod(g,k,p) which is a fast modular exponentiation function to compute \(g^k\boldmod p\text{.}\) Encoding-wise, we are using a smaller character set so that our messages encode to integers that are smaller than our prime \(p\text{.}\)
🔗
Now we will have Alice set up a public key \((p,g,A)\text{.}\) As with the Diffie-Hellman key exchange, Alice will choose a large safe prime \(p=2q+1\text{,}\) with \(q\) prime.
🔗
Now Alice creates the rest of her public key, keeping her integer exponent \(a\) private.
🔗
Bob now encodes a message as an integer and encrypts it using the Elgamal public key \((p,g,A)\text{.}\)
🔗
And now Alice decrypts the message using her private key \(a\text{,}\) making sure to convert the resulting integer back to a string.
🔗
