Sage example 9. Diffie-Hellman implementation.

Let’s implement the Diffie-Hellman key exchange protocol, taking some care to choose a large safe prime. We first create a list of primes of the form \(p=2q+1\) of a largish size, where \(q\) is prime.
🔗
Next let’s perform a key exchange with one of these primes. We will do our arithmetic within \(\F_p\text{,}\) as opposed to using congruences.
🔗
Now Alice and Bob will choose their random private exponents, exchange their computed powers, and compute the shared key.
🔗
Could Eve have determined \(K\) by solving the discrete log problem in this case? Let’s see if Sage can do it. We try to use Sage’s built-in discrete log function log().
🔗
It appears that primes \(p\) in the range \([2^{90},2^{91}]\) do not give rise to secure Diffie-Hellman key exchanges. See what happens when you replace qrange=2^90 with qrange=2^100, qrange=2^110, etc.. You will see that the Sage discrete log function log() running on a Sage finite field GF(p) quickly reaches its limitations.
